## Getting started

Use a JDK or import the individual Eclipse projects into a Java IDE. For example, from the repository root:

```bash
javac Conversion/src/BinaryToDecimal.java
java -cp Conversion/src BinaryToDecimal
```

Each class may have its own input flow; inspect the source before running it.
